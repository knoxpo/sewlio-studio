# Product Metrics

Project opens in under 1 second (small projects).

Project saves in under 500 ms.

Export to DST in under 2 seconds for a 100k-stitch design.

Support projects exceeding 1 million stitches.

# Engineering Metrics

>90% unit test coverage for Rust core crates.

Zero circular dependencies between packages.

All public APIs documented.

All architecture decisions recorded as ADRs.

No business logic inside Flutter widgets.

# User Experience Metrics

A first-time user can create, digitize, preview, and export a simple design without external documentation.

All primary actions are reachable via keyboard (desktop) and touch/stylus (tablet).

Consistent behavior across Windows, macOS, Linux, Web, iPadOS, and Android Tablet where platform capabilities allow.
