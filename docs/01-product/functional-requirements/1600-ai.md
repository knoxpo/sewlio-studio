# Purpose

The AI Platform augments the user's workflow by providing intelligent assistance throughout the embroidery design process.

AI is an assistant—not the source of truth.

Every AI action must produce the same commands a human user would generate manually.

The project remains completely usable without AI.

---

# Product Goals

The AI Platform shall

- Assist rather than replace
- Preserve determinism
- Respect user control
- Work with local models
- Support cloud models
- Maintain privacy
- Generate reproducible edits

---

# Design Philosophy

AI should never manipulate internal state directly.

Instead:

```text
User Request

↓

AI Reasoning

↓

Commands

↓

Command Bus

↓

Document

↓

Events

↓

UI Updates
```

AI is another client of the application.
