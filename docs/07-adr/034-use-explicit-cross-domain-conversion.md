# ADR-034: Use Explicit Cross-Domain Conversion

**Document ID:** ADR-034  
**Title:** Use Explicit Cross-Domain Conversion  
**Status:** Accepted  
**Date:** 2026-07-10  
**Owner:** Product Architecture Team

**Related Documents:** ARCH-037, ARCH-034, ARCH-032.

## Context

Designs may be reused across production domains, but production semantics are not equivalent.

## Decision

Use explicit conversion or derivation operations for cross-domain workflows.

## Consequences

Source projects are preserved. Lossy assumptions can be shown to the user. Target production data is regenerated by the target engine.

## Alternatives Considered

- Silent Project Type switching. Rejected because it can lose domain meaning.
- Shared output export from any project. Rejected because exporters need domain-specific readiness.

## Implementation Notes

Conversion commands are post-MVP unless required by a specific workflow.
