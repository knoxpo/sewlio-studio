# Purpose

This document defines the Husqvarna Viking / Pfaff VP3 Exporter used by Sewlio Studio.

The VP3 Exporter converts the Machine Intermediate Representation (MIR) into the VP3 embroidery format.

Unlike simpler formats such as DST, VP3 is a structured embroidery document capable of storing thread information, hoop definitions, metadata, and organized stitch blocks. It is widely used by modern Husqvarna Viking and Pfaff embroidery machines.  [oai_citation:0‡emborado](https://www.emborado.de/en/glossary/vp3-file/?utm_source=chatgpt.com)

---

# Domain Rules

The following always apply.

- VP3 Export consumes only Machine IR.
- Stitch block organization is preserved.
- Thread definitions are preserved whenever supported.
- Hoop information is mandatory.
- Export never performs optimization.
- Unsupported features generate diagnostics.
- Machine IR remains immutable.
- Export is deterministic.
- Export remains independent of editor state.
- Machine capabilities determine final serialization.
