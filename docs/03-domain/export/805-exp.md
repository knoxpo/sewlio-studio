# Purpose

This document defines the Melco EXP Exporter used by Sewlio Studio.

The EXP Exporter converts the Machine Intermediate Representation (MIR) into the Melco EXP embroidery format.

EXP is a lightweight stitch-based format originally developed for Melco commercial embroidery machines and is also supported by various Bernina embroidery systems. It is designed for efficient machine execution rather than rich document storage.  [oai_citation:0‡Melco Help Center](https://melco.zendesk.com/hc/en-us/articles/360018337572-Supported-File-Types?utm_source=chatgpt.com)

# Definition

The EXP Exporter converts

Machine IR

into

the Melco EXP binary format.

An EXP file primarily contains

```text
Machine Movements

Stitch Commands

Jump Commands

Color Change Commands

End Marker
```

The format intentionally contains

minimal metadata

and

no editable embroidery objects.  [oai_citation:1‡SewFlow](https://sewflow.com/blog/what-is-exp-file?utm_source=chatgpt.com)

# Responsibilities

The EXP Exporter performs

- binary generation

It does **not** perform

- simulation
- editing

# Coordinate Encoding

Machine coordinates

are converted

into

relative movements.

Each movement

represents

the change

from

the previous position.

Relative encoding

reduces

file size

and improves

machine efficiency.  [oai_citation:4‡Appropedia, the sustainability wiki](https://www.appropedia.org/EXP_Embroidery_File_Format?utm_source=chatgpt.com)

---

# Movement Resolution

The exporter

uses

the native

EXP movement resolution.

Coordinate precision

must conform

to

format requirements.

Machine coordinates

are normalized

before encoding.  [oai_citation:5‡Appropedia, the sustainability wiki](https://www.appropedia.org/EXP_Embroidery_File_Format?utm_source=chatgpt.com)

# Stitch Encoding

Every stitch

# Jump Encoding

Jump movements

# Domain Rules

The following always apply.

- EXP Export consumes only Machine IR.
- Coordinates are encoded as relative movements.
- Stitch order is preserved.
- Export never performs optimization.
- Thread definitions are not embedded in standard EXP.
- Unsupported features generate diagnostics.
- Machine IR remains immutable.
- Export is deterministic.
- Streaming export is supported.
- Export remains independent of editor state.
