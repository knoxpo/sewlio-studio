# Purpose

This document defines the Janome JEF Exporter used by Sewlio Studio.

The JEF Exporter converts the Machine Intermediate Representation (MIR) into the Janome JEF embroidery format.

JEF is the native embroidery format used by Janome embroidery machines and contains embroidery commands, hoop definitions, thread information, and machine-specific metadata.

The exporter produces standards-compliant JEF files while preserving the logical execution model represented by the MIR.

# Domain Rules

The following always apply.

- JEF Export consumes only Machine IR.
- Hoop validation is mandatory.
- Thread mapping uses the Janome thread palette.
- Export preserves execution order.
- Export never performs optimization.
- Unsupported features generate diagnostics.
- Machine IR remains immutable.
- Export is deterministic.
- Export remains independent of editor state.
- Machine capabilities determine final serialization.
