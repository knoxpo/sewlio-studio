# Purpose

This document defines the Brother PES Exporter used by Sewlio Studio.

The PES Exporter converts the Machine Intermediate Representation (MIR) into the Brother/Baby Lock/Bernina PES embroidery format.

Unlike DST, PES supports significantly richer metadata, thread information, hoop definitions, and version-specific capabilities.

The exporter generates standards-compliant PES files while preserving as much information from the MIR as the selected PES version allows.

# Domain Rules

The following always apply.

- PES Export consumes only Machine IR.
- Export behavior is version-aware.
- Thread information is preserved whenever supported.
- Metadata is preserved whenever supported.
- Export never performs optimization.
- Unsupported features generate diagnostics.
- Machine IR remains immutable.
- Export is deterministic.
- Export remains independent of editor state.
- Version capabilities determine encoded features.
