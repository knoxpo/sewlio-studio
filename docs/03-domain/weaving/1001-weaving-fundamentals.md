# Purpose

This document records baseline weaving concepts needed for future architecture and planning.

# Responsibilities

- Define warp and weft as separate yarn systems.
- Define picks, repeats, floats, selvage, denting, harnesses, lift plans, dobby control, and Jacquard hooks.
- Identify validation areas for future weaving projects.

# Rules

- Weaving terms must not be renamed into embroidery terms.
- Drafting and lift planning are production logic, not shared vector editing.
- Float analysis is a weaving validator concern.

# Out of Scope

- Numeric loom limits without a target loom profile.
- Vendor controller protocol details.

# Acceptance Criteria

- Future Weaving Engine docs have precise terminology.
- Shared design docs can reference weaving without claiming implementation.
