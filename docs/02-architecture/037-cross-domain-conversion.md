# Purpose

Cross-domain conversion creates a new project or derived design from another domain's design intent.

# Responsibilities

- Make conversion explicit and reversible where practical.
- Preserve original project data.
- Record assumptions, losses, and generated assets.
- Route converted output through the target Project Type's engine.

# Examples

- Create Print Project from Embroidery Design.
- Create Embroidery Project from Vector Artwork.
- Create Weaving Project from Print Artwork.

# Rules

- Conversion is not Project Type switching.
- Conversion must not overwrite the source project.
- Lossy conversion must produce diagnostics.
- Target-domain production data is regenerated by the target engine.

# Out of Scope

- Perfect automatic conversion between all textile domains.
- Silent conversion during export.

# Acceptance Criteria

- Product docs distinguish conversion from modes.
- Conversion output remains editable design intent where possible.
- Any generated production plan is derived in the target project.
